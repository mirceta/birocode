Strip branch filter OpenSpec: dock-strip-amendments — proposed

One amendment to the dashboard's horizontal agent strip: a three-state branch filter — show all agents, only those on main/master, or only those that aren't. Frontend-only, view-only, ephemeral.

Interactive mock — try the filter

The segmented control is the new part. Switch states and watch the strip narrow; note the +N chip when tabs are filtered out, and that dimmed-vs-bright (grid hidden/shown) never changes — the filter never touches visibility state. The ⇄ reorder toggle suspends the filter.

Docks NEW

The three states

All (default)Every roster tab renders — today's strip, untouched.
⎇ mainOnly tabs whose repo's current branch is main or master.
⎇ ≠mainOnly tabs whose branch is known and is neither. Unknown-branch tabs (fetch pending, repo unreadable) show only in All — the filter never guesses.
Filtered tabs keep full behavior (click still hides/shows the dock in the grid; dots, star, branch row unchanged). The selection is device-local and resets to All on reload — like reorder mode, it's strip view state, not roster state.

What it reuses (no new data, no backend)

Branch sourceThe per-repo git map the strip's branch row already reads (git[tab.repoId].branch). No new polling; a git refresh re-buckets tabs live.
Never loses an agentA non-All state that excludes tabs shows a +N hidden count, spoken in the control's accessible label too.
Reorder mode wins⇄ shows the full roster (every position reachable) and disables the filter; the selection reapplies on exit.
