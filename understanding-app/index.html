Reused, not invented: the dashboard's unseen-result latch

The harness's own dashboard already marks a finished agent: the dock tab's server-owned unseenResult latch, set when a builder run reaches done / error, drawn by the dock toolbar as a near-black exclamation dot, persisted in dock.json. This feature reuses that bit as THE state and that dot as THE visual language. Two things changed about it:
