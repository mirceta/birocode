Three triggers, no timer

What the harness will not do

  • Restart Chrome — it would close the Operator's windows. Nothing in the experiments needed it.
  • Enable, install or update the extension, or sign anyone in — Chrome protects those. The section has an Open … button that opens the right page in the right profile on the host; the Operator clicks once.
  • Reconnect a healthy browser — a reconnect makes the extension drop its connections for a moment, so it is sent only when something is wrong, and at most once in 20 s.
  • Refuse the turn — a browser-mode agent asked to fix code should not be stopped because Chrome is closed. The turn runs; the chat says what is not ready and what to do.

Eleven checks, and who repairs each

Ready needs a live proof. A machine with every file in place and no proof is degraded: "installed" alone is not "usable".

What Re-run does

One real agent turn, launched the way an agent's browser turn is — the same CLI, --chrome, ANTHROPIC_API_KEY removed, everything else inherited — with exactly two read-only browser tools allowed. It opens no tab, touches no page and writes no session file. The verdict is read from the turn's own event stream, never from what the model says.
