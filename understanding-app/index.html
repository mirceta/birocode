Two additions to the dashboard's horizontal agent strip: a queued-prompt ring on tab dots (finally visible for hidden docks) and show-all / hide-all bulk visibility controls. Frontend-only.

Dot states — the ring composes, it never replaces

The queued signal is today a thick black border on dock tiles only — a hidden dock's queue is invisible. The ring extends it to the strip using the same near-black language.
