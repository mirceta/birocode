2 · The armed 15-minute window — the fork you were in

After a healthy restart, swap.ps1 arms a scheduled task (ClaudeWebAutoRollback) set to fire in 15 minutes. Two exits: you disarm with keep.ps1, or the timer wins and rollback.ps1 restores last-good. Drag the clock or press the buttons.

Two ways out

keep.ps1 deletes the scheduled task — the new build stays live forever.
timeout → rollback.ps1 robocopy /MIRs run-bin.lastgood back over run-bin and restarts. No operator.

↳ In this session you said “keep it” inside the window — so we ran keep.ps1. The switch is off.

3 · The wrinkle in keep.ps1’s output

the line that matters

“disarmed … deleted”

keep.ps1 printed success first: the scheduled task was found and removed. The switch is off — no rollback fires. This build is now permanent.

the trailing ERROR

A harmless echo

The follow-up schtasks /Query I ran to confirm the task was gone returned “cannot find the file” — because it’s gone. The verify step succeeding is the not-found error.

Exit code 1 came from that confirmation query, not from keep.ps1 itself. Reading both lines together: disarm succeeded, and the proof is the “not found.”

4 · The safety rails baked into the deploy

before build

Ancestry guard

Refuses to deploy unless local HEAD already contains origin/main. Today it caught a sibling session shipping always-admin (94fead6) — so I merged origin/main first, and this deploy carries both features.

before stop

Stage-before-stop

The new build is fully staged and validated while the old one still serves. Only once the staged copy is proven complete does it kill the live PID — minimizing the dark window.

before swap

Snapshot → last-good

robocopy /MIR mirrors the current run-bin to run-bin.lastgood. That snapshot is exactly what the dead-man switch restores if the new build misbehaves.

this box’s gotchas

Two locale/tooling traps

Auto-rollback uses a real DateTime trigger (never schtasks /SD — locale bug). And the launcher is powershell.exe, not pwsh — there’s no PS7 here, so pwsh would silently no-op.
