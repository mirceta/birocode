🪟 Harness tabs land in the LEFT window — once and for all

Fleet task d3af3b9b · branch fix/harness-tabs-left-window · openspec harness-tabs-left-window

The answer in one screen

Root causeThe dashboard found its "launcher" tab in the other window by a window name. When the dashboard reloads after an error page (which is what a harness restart does to it), Chrome puts it in a new browsing-context group. The name then finds nothing, the lookup makes a blank tab in the dashboard's window, and every agent follows it there.
The fixA small 🪟 harness host tab lives in the left window. The dashboard talks to it over a same-origin BroadcastChannel: no names and no handles, so nothing a refresh can break. The host opens each agent tab next to itself.
The guardTabs of one Chrome window share the same screen rectangle. A host that is still in the dashboard's window only queues the agent and says "drag me left". An agent is never opened in the dashboard's window.
