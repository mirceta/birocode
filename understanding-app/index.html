Audit: what one dashboard browser asks the hub

The Management App only mounts the visible tab (or the open panes), so hidden tabs already do not poll. The Dashboard's per-dock pollers are all hidden-tab-guarded; what multiplied them was fifteen docks asking the same URL on the same tick — now one request per tick per URL (apiGet coalesces identical in-flight GETs).
