                  Would routing subagents through Claude Monitor stop them mixing with the main conversation?

                  Not by itself. Claude Monitor is a gateway that spawns the same claude CLI. A conversation's transcript lands in ~/.claude/projects/<the working directory, encoded>/ — Claude Monitor's own snapshot code writes exactly there (ClaudeService.RunFromSnapshot). Same checkout means same folder, whoever launches the CLI. The real run proves it: the parent's b57b9a4e… and the subagent's 1ae45677… sit side by side in one folder.
