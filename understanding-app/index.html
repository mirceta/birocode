🗂️ The Kanban's filters fold to one line

Fleet task 4e047c9e · openspec kanban-collapsible-filters. The filter controls are one shared component, TaskFilterBar, rendered by the Kanban and by the Task graph. It now has a fold: a chevron + Filters toggle with a badge; collapsed (the default) the controls give way to one line of summary chips, each with its own ×. The filter itself is untouched — the URL, the remembered filter and the chip counts behave as before. Try it below (keyboard too: Tab to the toggle, Enter / Space).

Live model

The fold is remembered per browser (localStorage claudeweb_task_filters_fold) and shared by every mounted bar, so the Kanban and the Task graph fold together. The sticky block is the fold; collapsed it is one line tall, and the board starts right under it.

Where each piece lives

taskFilterSummary.jsPure: summaryChips(filter, labels) — one chip per active value in bar order, the text search as one chip; withoutChip; activeCount; readFold / writeFold (default collapsed). Node-tested.
TaskFilterBar.jsxThe toggle (aria-expanded, Enter / Space), the collapsed line (chips, × per chip, clear all, "N of M tasks", the view's extra), the expanded controls exactly as before. One fold store per browser via useSyncExternalStore.
taskfilters.css.tf-fold is now the sticky block; .tf inside is static. Summary chips reuse the selected-chip look. The Task graph's pinned block makes the fold static, as it made the bar.
Not changedtaskFilterStore (URL + saved filter), taskFilters.js (matching, facets), the Kanban's columns and layout toolbar. No OR hint: the task search ANDs its words; the Status tab's hint describes a helper this bar does not use.
