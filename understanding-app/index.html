The handler (client/src/components/shared/workerWindow.js)

const w = window.open('', 'birocode-agent-' + key);   // EMPTY url: find, don't navigate
try { if (w.location.href === 'about:blank') w.location.href = url; }  // brand-new tab only
catch { /* existing cross-origin tab (a PEER harness) — just focus it */ }
w.focus();                                             // user gesture → Chrome switches to it

Why this works (6/6 against real Edge/Chromium — check-agent-tabs.mjs)

  • Find without reload: window.open('', name) returns the existing named tab WITHOUT navigating it — a marker planted in the tab survived the click. Only a brand-new tab (at about:blank) gets the deep link.
  • Distinct names never collide: one name per agent (sourceId|repoId key, sanitized) → clicking A then B gives two tabs; re-clicking never duplicates.
  • Focus crosses OS windows: a tab living in ANOTHER Chrome window is found by name and focus() (from the click's user gesture) switches to it in the window it lives in — measured visibility=visible + hasFocus=true.
  • Peer harness = cross-origin: reading location.href on an existing peer tab throws — which is exactly the "already exists" case, so the catch arm focuses without touching it.
  • Same plumbing as before: the URL still comes from the peer registry (agentWorkerHref) + the /studio?agent=<repoId> deep link; unknown machine → no click target, never a guessed URL.
