🏛️ Which model runs the arch agent — and why it was Opus 4.8

Fleet task 4e9f50be · openspec arch-model-fable. Nothing ever said "Opus". The arch's home folder is deliberately not a registered repo, so the one place a model is stored per agent (the registry's per-repo Model) had nothing for it. Both arch turn sites called the runner without a model, the Claude adapter emitted no --model, and the CLI chose for itself. Pick a turn and a setting below to walk the chain.

The chain, per turn

turn:
appsettings ArchModel: 


How to verify on a live harness: GET /api/arch now returns model; the Monitoring call log shows the arch turn's command line with --model claude-fable-5-1; the call record's Model (read from the CLI's init event) is the model that actually answered. Repo agents are untouched — their model stays per repo in the registry, chosen in the dock's model picker.
