Why the LAN can’t reach this harness

Diagnostic run on SQLBIROKRAT2 (192.168.0.211) — 2026-09-06, after deploying 553fb73 to :5099. The harness is healthy on localhost but unreachable from any other machine. Click a stage to see what was actually measured.

1. The journey of a LAN request

Four things must all say yes. Exactly one says no.

2. The installer’s checks — and the two that lied

installer/Services/DeployerService.cs has a 9-step deploy verifier. Run headlessly against this box, it reported a clean bill of health — wrongly. Toggle to see why.

Fixed 2026-09-06. Step 3 now reads the listening socket instead of HTTP-probing the box’s own IP, and says out loud that it proves the bind and not reachability. Step 6 now requires a matching rule to be genuinely unscoped (Program = Any and no AppContainer package) or scoped to ClaudeWeb.exe — it correctly reports CLOSED here.

3. Two different boxes

A trap worth naming: next5.birokrat.si/api/health returns 200, which looks like proof this box is reachable. It isn’t — it is a different machine. The health body gives it away.

4. The fix

One inbound rule. It needs Administrator — the agent session is not elevated, so a human runs this at the host PC. 

New-NetFirewallRule -DisplayName 'Claude Web backend (5099)' `
  -Direction Inbound -Protocol TCP -LocalPort 5099 `
  -Action Allow -Profile Private `
  -RemoteAddress 192.168.0.0/24

Before you open it: this box’s access code is still the default changeme, and LanBypassCidrs is 192.168.0.0/24 — so every device on the subnet clears the IP gate and only that default code stands between them and /api/*.

Change it with the “Set access code” button on the harness’s desktop window — that is the only sanctioned setter. OpenSpec add-desktop-access-code deliberately deleted the web endpoint (POST /api/auth/password), so there is no phone/web path by design.

Editing appsettings.json does nothing: AuthService.LoadOrSeed seeds %APPDATA%\ClaudeWeb\auth.json (a PBKDF2 hash) on first run and ignores the config value ever after. The config key is a first-run seed, not the live secret — which is also why a cold deploy onto a fresh box silently starts life on changeme.
