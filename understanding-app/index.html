JSON-RPC in, ToolOutcome {ok, status, detail, data} out — every result is data. Three new arms in the switch, three new methods in the toolbox

The Birokrat API tool is different in kind: an external node server the Operator configures per repo (key, URL, companies). The harness's own server needs no configuration — which is exactly why the Tools tab never showed it. Now it does (tab 5).
